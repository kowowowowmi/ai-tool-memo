# AIツール比較メモ

ブラウザだけで動作する、AIツールの名前・月額料金・メモを管理する小さなWebアプリです。

## ファイル構成

- `index.html`: 画面構造
- `style.css`: 見た目とスマートフォン対応
- `script.js`: 追加、編集、削除、検索、並べ替え、保存、CSV出力

## 動作確認方法

1. `index.html` をブラウザで開きます。
2. 初期JSONが画面下部に表示され、表にも初期データが表示されることを確認します。
3. 名前、月額料金、メモを入力して「追加する」を押します。
4. 追加した行の「編集」「削除」が動作することを確認します。
5. 検索欄に名前またはメモの一部を入力し、絞り込みされることを確認します。
6. 「昇順」「降順」で月額料金順に並び替えできることを確認します。
7. ブラウザを再読み込みし、localStorageに保存された内容が残ることを確認します。
8. 「初期状態へリセット」で確認画面が表示され、キャンセル時はデータが残り、承諾時は初期データに戻ることを確認します。
9. 「CSVダウンロード」で、現在の検索結果について日本語を含むCSVファイルが保存されることを確認します。
10. 料金欄に `1e3` や小数を入力したとき登録できないこと、名前欄に `=1+1` を入力した行のCSV値がアポストロフィから始まることを確認します。

## 入力チェック

- 名前、月額料金、メモは必須です。
- 月額料金は0円以上の整数のみ登録できます。
- 同じ名前のツールは重複登録できません。
- 料金欄の指数表記や小数、JavaScriptで正確に扱えない大きな数は受け付けません。

## 安全な表示

ユーザー入力は `textContent` を使って画面に表示しています。入力された文字列をHTMLとして実行しないため、`<script>` のような文字を入力してもコードとして動きません。

CSVでは、表計算ソフトで数式と解釈され得る文字から始まる名前・メモに先頭のアポストロフィを付けています。初期状態へのリセット前には確認画面を表示します。

## 初稿から修正した点

- 料金の判定を数値変換だけに頼らず、数字の書式と安全な整数範囲を確認するようにしました。指数表記など、意図しない入力が通ることを防ぐためです。
- CSV出力時に数式として解釈され得る文字列を保護しました。入力した名前・メモを表計算ソフトで開く際の危険を減らすためです。
- リセット前に確認画面を追加しました。保存済みのデータを誤操作で消さないためです。
